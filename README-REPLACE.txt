SAEED PORTFOLIO — PREMIUM V2

هذه نسخة كاملة جاهزة للاستبدال داخل مشروع saeed-digital-craft-main.

أهم التحديثات:
- تصميم Premium Tech عربي أولاً.
- Dark / Light mode مع حفظ الاختيار في localStorage.
- شخصية سعودية تقنية داخل الـHero.
- Hero موجه لمسؤول التوظيف: التخصص + القيمة + الخبرة + GPA + المشروع.
- CTA واضحة بدون تكرار مزعج.
- Typography محسنة للعربي والإنجليزي.
- حركات reveal وhover وfloating خفيفة مع دعم prefers-reduced-motion.
- Navbar زجاجي ويتغير عند النزول.
- تحسين التباين والألوان في الوضعين.
- CV موجود داخل public.
- إزالة LinkedIn من المحتوى.

التشغيل:
1) افتح PowerShell داخل مجلد المشروع.
2) npm install
3) npm run dev

ثم افتح الرابط الذي يظهر لك في PowerShell (غالباً 5173 أو منفذ آخر متاح).
