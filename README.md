03 — TYPOGRAPHY

Arabic typography is extremely important.

The biggest requirement:

NEVER render broken, disconnected, ugly, or poorly shaped Arabic.

Arabic must use a proper Arabic webfont with correct shaping, ligatures and RTL behavior.

Prefer a premium Arabic typeface with a personality similar in sophistication to Thmanyah’s typography.

If the project can legally load the official Thmanyah font through an appropriate web-compatible method, use it according to its license.

Otherwise use an equally premium Arabic font.

Recommended direction:

Arabic:

* Thmanyah Sans / Thmanyah Serif where technically and legally appropriate
* Otherwise a premium modern Arabic font with excellent Arabic shaping

English:

Use a refined modern sans-serif such as:

* Inter
* Geist
* Manrope
* Plus Jakarta Sans

Use typography deliberately.

Large Arabic headlines should feel editorial and expensive.

Avoid:

* generic Arial
* default system Arabic
* cheap-looking rounded Arabic fonts
* excessive font weights
* tiny text
* cramped line-height

Arabic typography should be treated as a major visual component, not an afterthought.
